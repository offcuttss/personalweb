## 目录结构

```
personalweb/
├── index.html          # 页面本体（所有内容都写在这里，直接改它即可）
├── css/
│   └── style.css        # 样式（粉紫渐变主题、响应式）
├── assets/
│   └── avatar.jpg       # 头像图片
└── README.md
```

> 说明：`js/` 目录为早期版本遗留（动态渲染方案），当前页面为纯静态 HTML，不再依赖 JavaScript，无需关注。

## 如何预览

直接用浏览器打开 `index.html` 即可，无需任何构建步骤或服务器。

## 如何修改内容

所有文案都直接写在 `index.html` 中，搜索 `↓↓↓` 注释可快速定位每个可改区域：

- **头像**：替换 `assets/avatar.jpg` 同名文件
- **姓名 / 简介 / 链接**：改 HTML 顶部对应文字与 `href`
- **技能**：在「技能」板块找到对应的 `.skill` 块，改文字并把 `width:85%` 改成你的熟练度百分比（0–100）
- **正在进行 / 项目**：复制对应的 `.card` 代码块，修改标题、描述、标签和链接即可新增一条

修改后保存，刷新浏览器即可生效。
